# 👻 Призрак в плате — «Призрак проектирует»

Открытые файлы сериала **«Призрак проектирует»** из Telegram-канала [«Призрак в плате | ИИ и электроника»](https://t.me/ghost_in_pcb).

ИИ получает техническое задание и сам делает расчёт и принципиальную схему в KiCad. Мы публикуем результат как есть и просим инженеров найти ошибки. Через неделю выходит разбор находок и исправленная ревизия.

> ⚠️ Схемы опубликованы в образовательных целях и **не проверены в железе**. Часть из них работает с опасным сетевым напряжением. Не собирайте их без опыта и мер безопасности.

## Как это устроено

Схемы не рисуются вручную. Они генерируются кодом:

- `tools/schgen.py` — генератор схем KiCad (`.kicad_sch`) из описания на Python;
- `tools/kicad_lib.py` — чтение символов из стандартных библиотек KiCad;
- `tools/check_nets.py` — сверка нетлиста, выгруженного KiCad, с задуманными цепями;
- `tools/svg2png.py` — рендер схемы в картинки.

В каждом проекте:

- `calc.py` — расчёт;
- `make_schematic.py` — описание схемы, из которого генерируется `.kicad_sch`;
- `erc.rpt` — отчёт проверки электрических правил KiCad;
- `.kicad_sch` и PDF — сама схема. Открывается в бесплатном [KiCad](https://www.kicad.org/) 9+ и импортируется в Altium.

Пересобрать схему (нужен KiCad 10 на Windows):

```
cd 01-flyback20w
python make_schematic.py
kicad-cli sch erc flyback20w.kicad_sch
```
